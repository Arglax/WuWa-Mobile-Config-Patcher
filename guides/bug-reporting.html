Reporting Bugs & Getting Support

For Game-Related Crashes or Visual Issues

Go to the Utilities tab $\rightarrow$ tap Get Device Info (copy specs) $\rightarrow$ tap Decrypt Log $\rightarrow$ tap Share Decrypted Log. Send both files in Discord #issues-and-concerns.

For Config Patcher App Bugs

  1. Go to the Support tab.
  2. Tap Report a Bug / Suggest a Feature.
  3. Select Bug Report, describe the issue, and send via email or Discord.
