Live Config Editor & Section Rules

Access the Editor tab to tweak active on-device config files directly (Engine.ini and DeviceProfiles.ini).

Smart Mode
  • Structured section cards with add/edit/delete controls.
  • Sort A-Z Button: Instantly sorts CVars alphabetically per section.
  • Auto-Fix Button: Re-categorizes CVars into standard UE section headers automatically.
Text Mode
  • Full manual syntax-highlighted raw text editor.
  • Isolation Search Mode: Filters raw text line-by-line.
  • Live line numbers and search/replace tools.
One-Line Mode
  • Tailored key-value editor for rapid single CVar adjustments.
  • Includes live raw buffer preview at the bottom.

Engine Section Guard Rules

Misplaced CVars are displayed in Vibrant Red across all editor views. When saving, if misplaced CVars exist, the app prompts you with an Auto-Fix Sections remediative action or the option to proceed with "I know what I'm doing".

DEVICEPROFILES.INI RULE

In DeviceProfiles.ini, CVar entries are automatically formatted as CVars=Key=Value. Metadata lines (e.g. BaseProfileName, DeviceScore) remain un-prefixed.
