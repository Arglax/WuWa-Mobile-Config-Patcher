Getting & Applying Config Presets

WuWa Config Patcher provides three seamless repository sources to fetch and inject graphics presets:

Method 1: Default Repository (Arglax & Community Presets)

  1. Open the Config tab.
  2. Set Repository Source to Arglax (Default).
  3. Tap Sync Files & Refresh to download the latest graphics presets.
  4. Select your target device preset (e.g. Snapdragon 8 Gen 3 - Extreme).
  5. Tap 1-Click Patch.

Method 2: Custom Online Repository (.zip Download Link)

  1. Go to Config tab $\rightarrow$ select Custom Online Repository.
  2. Paste the direct URL to your custom .zip config pack.
  3. Tap Sync Files & Refresh and apply via 1-Click Patch.

Method 3: Local Repository (On-Device Folder)

  1. Go to Config tab $\rightarrow$ select Local Repository.
  2. Tap Select Folder and pick the directory containing your custom config files.
  3. Tap Use this Folder, sync, and apply via 1-Click Patch.
PER-FILE PATCHING

To apply only a specific file (e.g. Engine.ini without touching DeviceProfiles.ini), tap the Gear Icon (⚙️) beside 1-Click Patch.
