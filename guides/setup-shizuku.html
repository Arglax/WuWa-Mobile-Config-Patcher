Setting Up Shizuku & Developer Options

WHY SHIZUKU IS REQUIRED

Android 11+ enforces strict Scoped Storage. Shizuku grants elevated access to inject and backup files inside Android/data/com.kurogame.wutheringwaves.global safely.

Step 1: Enable Developer Options

  1. Open phone Settings.
  2. Go to About Phone $\rightarrow$ Software Information.
  3. Tap Build Number 7 times continuously until Developer Mode activates.

Step 2: Start Shizuku via Wireless Debugging

  1. Open Shizuku app.
  2. Tap Pairing $\rightarrow$ Open Developer Options.
  3. Enable Wireless Debugging $\rightarrow$ Tap Pair device with pairing code.
  4. Enter the 6-digit code into Shizuku's notification prompt.
  5. Return to Shizuku and tap Start.
