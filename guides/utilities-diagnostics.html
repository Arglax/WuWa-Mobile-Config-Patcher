Utilities Suite & Diagnostics Guide

Access the Utilities tab for deep hardware scans, log tools, and persistent backups:

Get Device Info

Scans hidden hardware specs (GPU model, physical RAM, CPU cores, Device Score) extracted directly from game logs.

Log Decryptor & Explorer

Decrypts obfuscated Client.log files with an inline line explorer, filter chips (LogConfig, Vulkan, RHI), and full-screen viewer.

Duplicate Flagger

Scans active INIs for duplicate CVar entries across lines and sections, allowing 1-tap resolution while protecting metadata.

Strip Forbidden CVars

Detects and strips forbidden CVars that get ignored or deleted at runtime by game code (harmless at startup, no crashes).

CVar Bank & Reference

Searchable reference database of 1000+ CVars with Card and Table views, source filters, and 1-tap Send to Editor insertion.

Main Storage Reader

Persistent storage containing timestamped live INI backups with 1-tap Restore Backup capability.
