Overview & Core Capabilities

Maintained by Arglax

WuWa Config Patcher (io.github.arglax.configpatcher — Version v1.9.0, versionCode = 73) is an elevated Android utility designed to grant mobile players 1-tap graphics patching, side-by-side CVar diffing, custom color themes, and real-time analytics while providing config creators, tweakers, and developers with deep INI editing, pre-save Garbage Collection guards, DeviceProfiles CVar protection, automated App Doctor self-repair, and raw engine diagnostics for Wuthering Waves.

Elevated Access Backend Hierarchy

Maintained by Arglax

Because Android 11+ enforces Scoped Storage, WuWa Config Patcher dynamically detects and utilizes 5 elevated access backend states:

ROOT

Native SU Shell

Managed via topjohnwu libsu Core (v6.0.0). Grants non-interactive direct root shell execution.

SHIZUKU

Wireless Debugging / ADB

Managed via ShizukuManager.kt (`rikka.shizuku.api`). Wireless ADB IPC execution requiring zero root.

AXMANAGER

Axeron Shell Provider

Managed via AxManagerManager.kt. Axeron community manager service binder execution for non-rooted elevated IPC.

SHIZUKU_UNAUTHORIZED

Pending Permission

Shizuku service binder detected running on device, but application permission prompt is pending.

NONE

No Access Available

No elevated access detected. App prompts setup wizard or falls back to manual export mode.
