Overview & Core Capabilities

By Arglax • 100% Free & Open Source

WuWa Config Patcher (io.github.arglax.configpatcher) is an elevated Android utility designed to grant mobile players 1-tap graphics patching while providing config creators, tweakers, and developers with deep INI editing, real-time CVar section enforcement, and raw engine diagnostics for Wuthering Waves.

System Invariants & Storage Paths

Target SDK 36 (Android 11–15+)

Because Android 11+ enforces Scoped Storage (Storage Access Framework), the patcher resolves package paths dynamically and uses elevated IPC to perform direct atomic writes.

Target Component Absolute Scoped Storage File Path
Config Directory /storage/emulated/0/Android/data/<package>/files/UE4Game/Client/Client/Saved/Config/Android/
Active INI Files Engine.ini, DeviceProfiles.ini, Scalability.ini, GameUserSettings.ini
Runtime Logs /storage/emulated/0/Android/data/<package>/files/UE4Game/Client/Client/Saved/Logs/Client.log
Launch Flags /storage/emulated/0/Android/data/<package>/files/UE4Game/Client/UE4CommandLine.txt
Shader Caches .../files/VulkanProgramBinaryCache (Vulkan) & .../files/ProgramBinaryCache (OpenGL)
SUPPORTED GAME VARIANTS
The patcher automatically detects and resolves: com.kurogame.wutheringwaves.global, com.kurogame.wutheringwaves.bilibili, com.kurogame.wutheringwaves.kuro, com.kurogame.wutheringwaves.tw, com.kurogame.wutheringwaves.jp, and com.kurogame.wutheringwaves.kr.
