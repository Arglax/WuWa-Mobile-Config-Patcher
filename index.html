Prerequisites & Setup Guide

Android's strict scoped storage prevents apps from reaching Android/data/com.kurogame.wutheringwaves.global directly. To grant permissions, you must use Shizuku.

IMPORTANT REQUIREMENT

Developer Options must be activated on your Android device to start Shizuku via Wireless Debugging or ADB.

How to Enable Developer Options

  1. Open the Settings app on your Android phone.
  2. Navigate to About Phone or Software Information.
  3. Locate Build Number and tap it 7 times in quick succession.
  4. You will see a toast confirming: "You are now a developer!".
  5. Return to main Settings and locate Developer Options under System or Additional Settings.

Setting Up Shizuku

  1. Launch the Shizuku app.
  2. Enable Wireless Debugging in Android Developer Options.
  3. Tap Pairing in Shizuku, enter the 6-digit Wireless Debugging code.
  4. Tap Start in Shizuku until the status turns "Shizuku is running".
  5. In WuWa Config Patcher, go to Settings $\rightarrow$ Shizuku Check and grant access.

Getting & Applying Configs

Choose from three seamless repository sources to fetch and inject graphics presets:

Method 1: Default Repository (Recommended)

  1. Go to the Config tab.
  2. Set Repository Source to Arglax (Default).
  3. Tap Sync Files & Refresh.
  4. Select your desired preset (e.g. Snapdragon 8 Gen 3 - Extreme).
  5. Tap the big 1-Click Patch button.

Method 2: Custom Online Repository (.zip Download Link)

  1. Go to the Config tab.
  2. Set Repository Source to Custom Online Repository.
  3. Enter a direct .zip download URL.
  4. Tap Sync Files & Refresh and apply via 1-Click Patch.

Method 3: Local Repository (On-Device Folder)

  1. Go to the Config tab $\rightarrow$ select Local Repository.
  2. Tap Select Folder and pick the directory containing your custom config zips/files.
  3. Tap Use this Folder, sync, and apply via 1-Click Patch.
PRO TIP: PER-FILE PATCHING

Want to apply only Engine.ini without overwriting DeviceProfiles.ini? Tap the Gear Icon (⚙️) beside 1-Click Patch and choose specific files to patch!

Reverting to Vanilla & Advanced Revert

If you experience unexpected stutters or want to revert back to official Kuro Games default graphics:

  • Full Vanilla Revert: Go to Utilities tab $\rightarrow$ tap Revert to Vanilla $\rightarrow$ Confirm. This wipes active modified configs.
  • Advanced Revert: Tap Advanced Revert in Utilities to selectively choose and delete individual config files (e.g., deleting only Engine.ini while keeping DeviceProfiles.ini).

Engine CVar Guards & Section Rules

To prevent game engine overrides, the editor enforces canonical Unreal Engine section placement rules:

Category Canonical Section Header Guard Rule & Prefix
Rendering [/Script/Engine.RendererSettings] Any CVar starting with r. (except r.SupportAllShaderPermutations).
Rendering Override [/Script/Engine.RendererOverrideSettings] Accepts r.SupportAllShaderPermutations, any r. CVars, or dp. commands. Whitelisted during Auto-Fix.
Streaming [/Script/Engine.StreamingSettings] Any CVar starting with s..
Garbage Collection [/Script/Engine.GarbageCollectionSettings] Any CVar starting with gc..
Network Settings [/Script/Engine.NetworkSettings] Specifically for n.VerifyPeer, p.EnableMultiplayerWorldOriginRebasing, and NetworkEmulationProfiles.
Cooker Settings [/Script/UnrealEd.CookerSettings] Any CVar starting with cook..
Whitelisted Sections [Core.Paths] / [Core.System] Paths and system settings are completely whitelisted and never flagged or moved.
General Container [SystemSettings] / [ConsoleVariables] General blocks that accept ANY CVars safely.
VIBRANT RED HIGHLIGHTING & AUTO-FIX

Misplaced CVars are displayed in Vibrant Red across all editor views. When saving, if misplaced CVars exist, the app prompts you with an Auto-Fix Sections remediative action or the option to proceed with "I know what I'm doing".

DEVICEPROFILES.INI RULE

In DeviceProfiles.ini, CVar entries are automatically formatted as CVars=Key=Value. Metadata lines (e.g. BaseProfileName, DeviceScore) remain un-prefixed.

Enabling C# Environment

Kuro Games developed an updated C# scripting environment for Wuthering Waves. You can force enable this engine flag to improve script execution performance:

  1. Go to the Editor tab.
  2. Select Misc Patch at the bottom.
  3. Check -ForceEnableCSharpEnvironment (and optionally -SkipSplash).
  4. Tap Patch.

How to Verify C# Environment is Active

  • In-Game Client Indicator: Launch Wuthering Waves. Look at the top-right or bottom-left client version text. If an asterisk (*) appears at the end of the version string, C# is active!
  • Log Verification: Run Decrypt Log in Utilities $\rightarrow$ search for Sharphereal. If present with initialization logs, C# is active.

To disable C#, return to Misc Patch and tap Remove File.

Utilities Suite & Diagnostics

Access the Utilities tab for deep hardware scans, log tools, and persistent backups:

Get Device Info

Scans hidden hardware specs (GPU model, physical RAM, CPU cores, Device Score) extracted directly from game logs.

Log Decryptor & Explorer

Decrypts obfuscated Client.log files with an inline line explorer, filter chips (LogConfig, Vulkan, RHI), and full-screen viewer.

Duplicate Flagger

Scans active INIs for duplicate CVar entries across lines and sections, allowing 1-tap resolution while protecting metadata.

Strip Forbidden CVars

Detects and strips forbidden CVars that get ignored or deleted at runtime by game code (harmless at startup, no crashes).

CVar Bank & Reference

Searchable reference database of 1000+ CVars with Card and Table views, source filters, and 1-tap Send to Editor insertion.

Main Storage Reader

Persistent storage containing timestamped live INI backups with 1-tap Restore Backup capability.

  2. Tap Report a Bug / Suggest a Feature.

Manual Mode Guide (Old School)

For users who prefer applying configs manually without using the automated patcher app:

Game Config Target Directory
/storage/emulated/0/Android/data/com.kurogame.wutheringwaves.global/files/UE4Game/Client/Client/Saved/Config/Android
  1. Download Engine.ini or DeviceProfiles.ini from Arglax's GitHub repository.
  2. Ensure the file extension is strictly .ini (if saved as .ini.txt, rename it to remove .txt).
  3. Use a Shizuku-enabled file manager (such as MT Manager or ZArchiver) to copy the files into the Android directory listed above.
  4. Launch Wuthering Waves.
