Engine Section & Diagnostic Guide (v1.9.0 • Build 73)

Tab 3: UtilitiesScreen > Advanced Subtab

The Advanced Subtab in version 1.9.0 (versionCode 73) provides a comprehensive toolkit for config creators, preset developers, and engine tweakers. It includes Section Guards, CVar Analyzer, 1000+ CVar Bank, Duplicate CVar Flagger, Forbidden CVar Stripper, and CVar Extractor.

CANONICAL SECTION PREFIX CHIPS
  • r. → [/Script/Engine.RendererSettings]
  • s. → [/Script/Engine.StreamingSettings]
  • gc. → [/Script/Engine.GarbageCollectionSettings]
  • cook. → [/Script/UnrealEd.CookerSettings]
  • [SystemSettings] → Universal container for all general CVars.

1. Engine CVar Section Guards

CVarSectionGuard.kt

Unreal Engine requires specific Console Variables (CVars) to be declared under their correct section headers in Engine.ini and DeviceProfiles.ini. Placing CVars in wrong sections or prepending invalid CVars= prefixes causes the game engine to ignore them completely.

Section Routing & Auto-Fix Logic (CVarSectionGuard.kt)

  • Canonical Routing: Automatically routes prefixed variables to appropriate sections (e.g., r.* commands to [/Script/Engine.RendererSettings], s.* commands to [/Script/Engine.StreamingSettings], gc.* commands to [/Script/Engine.GarbageCollectionSettings], and cook.* commands to [/Script/UnrealEd.CookerSettings]).
  • Prefix Stripping: Identifies and strips illegal CVars= or +CVars= prefixes that break INI parsing.
  • Whitelisted Sections: Automatically preserves custom engine sections such as [Core.Paths], [Core.System], and [/Script/Engine.RendererOverrideSettings] without modification.
  • 1-Tap Auto-Fix: When saving configs in the Live Config Editor, section violations are flagged in vibrant red and can be fixed with a single tap.

2. Config Analysis Tool (CVar Analyzer)

CVarAnalyzer.kt

The Analyze Config tool invokes CVarAnalyzer.kt to cross-check active on-device INI CVars against the execution stream of decrypted Client.log files. It resolves the latest instance near log end to determine whether your commands applied successfully, failed, or were stripped by the game engine.

Config Analysis Report (ConfigAnalysisDialog.kt)

  • Summary KPIs: Total CVars, Applied %, Failed count, Deleted/Ignored count & %.
  • Collapsible Smart Insights Panel: Analyzes potential engine bottlenecks, rendering conflicts, and provides actionable tuning recommendations.
  • Combined Single Horizontal Filter Bar: Features a tap-to-cycle CVar Filter (All → Applied → Failed → Deleted) combined with a File Filter (All Files → Engine.ini → DeviceProfiles.ini).
  • Copy & Save Scope Dialogs: Selectively copy or export either the Full Report or Filtered CVar Names Only.

4. INI Integrity & Cleanup Tools

Duplicate Flagger & Forbidden Stripper
🔁

Duplicate CVar Flagger

Invokes DuplicateCvarFlagger.kt to scan active INIs for duplicate keys across lines and sections while protecting metadata profile pointers (BaseProfileName, DeviceScore). Displays DuplicateFlaggerDialog.kt for 1-tap resolution.

🚫

Forbidden CVar Stripper

Invokes ForbiddenCvarStripper.kt to detect forbidden or blacklisted CVars that the game engine flags to be ignored or deleted automatically at runtime (note: forbidden CVars do not cause game crashes). Displays ForbiddenCvarDialog.kt with a 1-tap Auto Strip All action.

5. Log Extraction & Main Storage Reader

CVarExtractor.kt & MainStorageReaderDialog.kt
CVar Extractor

Extract Log CVars (CVarExtractor.kt)

Parses decrypted Client.log line-by-line and assigns change frequency remarks:

  • Static — Constants loaded once during engine initialization.
  • Var 1 / Var 2 / Var 3 — CVars modified during scene loading or graphic changes.
  • Hyper — Rapidly updating runtime CVars per frame.

Displays CVarExtractorDialog.kt with 1-tap Save Cvars Only (exports r.* console variable keys to Main Storage), Export TXT, and CSV export options.

Main Storage

Main Storage Reader (MainStorageReaderDialog.kt)

Inspects persistent backups stored in context.filesDir/app_main_storage/.

  • View, copy, or share timestamped INI backups.
  • 1-tap Restore Backup button to revert to any previous configuration snapshot instantly.
