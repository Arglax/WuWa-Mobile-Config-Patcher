Reporting Bugs & Getting Support[cite: 8]

For Game-Related Crashes or Visual Issues[cite: 8]

Go to the Utilities tab $\rightarrow$ tap Get Device Info (copy specs) $\rightarrow$ tap Decrypt Log $\rightarrow$ tap Share Decrypted Log. Send both files in Discord #issues-and-concerns.[cite: 8]

For Config Patcher App Bugs[cite: 8]

  1. Go to the Support tab (Tab 5).[cite: 1]
  2. Tap Report a Bug / Suggest a Feature.[cite: 8]
  3. Select Bug Report. This opens BugReportDialog.kt which automatically generates a technical report attached with your device diagnostics and backend activity_log.txt.[cite: 1]
  4. Send directly via Email or Discord.[cite: 1]
ADDITIONAL SUPPORT RESOURCES

The Support screen also provides direct links to Arglax's official Discord and GitHub, a showcase card for the WuWaLab Companion app, and GCash/InstaPay donation dialogs (GCashDialog.kt)[cite: 1].
