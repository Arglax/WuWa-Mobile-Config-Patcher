Support, Bug Reporting & Activity Logger

Tab 5: SupportScreen

WuWa Config Patcher automatically tracks all internal transactions, file operations, Shizuku IPC binder calls, and exceptions via ActionLogger.kt to ensure full diagnostic traceability.

📋

Activity Logger Traceability

All operations are logged in context.filesDir/activity_log.txt. You can inspect this anytime under Utilities > Common > View Backend Activity Log.

🐛

Report a Bug Generator

Tap "Report a Bug / Suggest a Feature" on the Support tab to open BugReportDialog.kt. It compiles device hardware specs and backend logs to submit via Discord or GitHub Issues.

☕

Donations & Creator Support

WuWa Config Patcher is 100% free and ad-free. You can support Arglax directly via the in-app GCash / InstaPay QR dialog.

Settings: Danger Zone Actions

Tab 4: SettingsScreen > Danger Zone

Guarded 3-step confirmation actions for system cleanup and cache maintenance:

AVAILABLE DANGER ZONE ROUTINES
  • Clear App Cache & History: Wipes temporary repository zip caches and editor undo/redo snapshot stacks.
  • Clear App Data & Exports: Complete factory reset for all custom repo URLs, exports, and preferences.
  • Clear Activity Log: Erases activity_log.txt.
  • Delete Shaders: Opens DeleteShadersDialog.kt to wipe Vulkan (VulkanProgramBinaryCache) or OpenGL (ProgramBinaryCache) compiled shader caches to fix rendering artifacts after game updates.
