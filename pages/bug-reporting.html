Support & Diagnostic Bug Reporting

Tab 5: SupportScreen

WuWa Config Patcher automatically tracks all internal transactions, file operations, Shizuku IPC binder calls, and exceptions via ActionLogger.log(context, message) and ActionLogger.logException(context, title, throwable).

📋

Activity Logger Traceability

All operations are logged in context.filesDir/activity_log.txt. You can inspect this anytime under Utilities > Common Subtab > View Backend Activity Log.

🐛

Report a Bug Generator (BugReportDialog.kt)

Tap "Report a Bug / Suggest a Feature" on the Support tab to open BugReportDialog.kt. Supports 3 feedback categories (Bug Report, Feature Request, General Feedback) and interactive screen checkboxes (Config, Editor, Utilities, Support, Settings and sub-features). It compiles system hardware specs, app version, elevated access status, and recent action log lines to submit via Email, Discord, or GitHub Issues.

☕

Donations & Creator Support

WuWa Config Patcher is maintained by Arglax as a free project. You can support development directly via the in-app GCash / InstaPay QR dialog (GCashDialog.kt).

DEVELOPER NOTES & RELEASE REPOSITORY
View release notes maintained by Arglax regarding the platform migration to WuWa-Mobile-Config-Patcher on GitHub. Tap "Visit New Release Repository" on the Support tab to access releases directly at GitHub Releases.

Settings Preferences & System Toggles

Tab 4: SettingsScreen > Preferences

The Preferences Card on the Settings tab allows customizing application behavior, feedback cues, notification schedules, and information clarity:

🌐

App Language Selector

Change overall application localization language (via I18n.kt), supporting English, Chinese, Japanese, Korean, Spanish, Portuguese, Indonesian, Vietnamese, Tagalog, and Arabic.

💡

Help Tooltips

Toggle the visibility of interactive help icons and (?) buttons throughout the application layout.

🔔

Patch Notifications

Opt in or out of push notifications when new config update releases and preset packages are published.

📳

Haptics

Enable or disable physical device vibration feedback on button presses, saves, and action completions.

🔊

Sound Effects

Toggle audio feedback, including button click sounds and synthesized success or error audio beeps (AppSoundManager.kt).

🌙

DND at Work

Automatically mutes patch release push notifications during local office/work hours (8:00 AM – 5:00 PM local time).

🤪

Stupid Mode (Default: ON)

Described in-app as "Make information clearer and easier to spot. 90% Spoonfeeding." When enabled, every status, warning, or error message displays as a full, standalone dismissible popup window (StatusPopupDialog.kt) carrying explicit remediation instructions (e.g. step-by-step guidance to start Shizuku or fix invalid inputs) instead of a quick-fading toast notification. Disabling this toggle restores standard lightweight Android toast messages.

Settings Screen: Danger Zone Actions

Tab 4: SettingsScreen > Danger Zone

Normally collapsed in Settings. Expanding the Danger Zone reveals 3-step guarded confirmation actions for system cleanup and cache maintenance:

Guarded System Maintenance Routines

  • Clear App Cache & History: Wipes temporary repository zip caches, staging files, and editor undo/redo snapshot stacks.
  • Clear App Data & Exports: Complete factory reset clearing custom repository URLs, exported zips, and preference toggles.
  • Clear Activity Log: Erases context.filesDir/activity_log.txt.
  • Delete Shaders (DeleteShadersDialog.kt): Deletes Vulkan (VulkanProgramBinaryCache) or OpenGL (ProgramBinaryCache) compiled shader caches to fix rendering artifacts after game updates.
