Live Config Editor & Section Rules[cite: 9]

Access the Editor tab to tweak active on-device config files directly (Engine.ini, DeviceProfiles.ini, GameUserSettings.ini). Files are read via ShizukuManager.readLogFile() and cached in memory for zero-latency tab switching[cite: 1].

Smart Mode
  • Structured section cards with add/edit/delete controls.[cite: 9]
  • Sort A-Z Button: Instantly sorts CVars alphabetically per section (sortSmartSectionsAlphabetically())[cite: 1].
  • Multi-Select & Bulk Delete: Allows checking multiple items in expanded sections to delete them in a single batch[cite: 1].
  • Auto-Fix Button: Re-categorizes CVars into standard UE section headers automatically based on CVarSectionGuard.kt[cite: 1].
Text Mode
  • Full manual syntax-highlighted raw text editor.[cite: 9]
  • Isolation Search Mode: Filters raw text line-by-line.[cite: 9]
  • Adjustable font size slider (8sp to 24sp) and Search/Replace tools with "Replace Next" and "Replace All"[cite: 1].
One-Line Mode
  • Tailored key-value editor for rapid single CVar adjustments via interactive "Add CVar" and "Edit CVar" dialogs[cite: 1].
  • Includes real-time section guard validation notes and a live buffer preview card at the bottom[cite: 1].

Engine Section Guard Rules (CVarSectionGuard.kt)[cite: 1]

Misplaced CVars are displayed in Vibrant Red (#FF2222) across all editor views. When saving, if misplaced CVars exist, the app prompts you with an Auto-Fix Sections remediative action or the option to bypass with "I know what I'm doing"[cite: 1].

Canonical Section Header Prefix Guard Enforcement[cite: 1]
[/Script/Engine.RendererSettings] Any CVar starting with r. (except r.SupportAllShaderPermutations)[cite: 1].
[/Script/Engine.RendererOverrideSettings] Accepts r.SupportAllShaderPermutations, any r. CVars, or dp. commands. Whitelisted during Auto-Fix[cite: 1].
[/Script/Engine.StreamingSettings] Any CVar starting with s.[cite: 1].
[/Script/Engine.GarbageCollectionSettings] Any CVar starting with gc.[cite: 1].
[/Script/Engine.NetworkSettings] n.VerifyPeer, p.EnableMultiplayerWorldOriginRebasing, NetworkEmulationProfiles[cite: 1].
[/Script/UnrealEd.CookerSettings] Any CVar starting with cook.[cite: 1].
[SystemSettings] / [ConsoleVariables] Universal blocks that safely accept ANY CVars[cite: 1].
[Core.Paths] / [Core.System] Strictly whitelisted. NEVER flagged, moved, or altered during Auto-Fix[cite: 1].
DEVICEPROFILES.INI RULE

In DeviceProfiles.ini, CVar entries are automatically formatted as CVars=Key=Value. Metadata lines (e.g. BaseProfileName, DeviceScore) remain un-prefixed and preserved untouched[cite: 1].
