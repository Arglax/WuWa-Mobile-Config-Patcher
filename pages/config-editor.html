Config Editor

The built-in Config Editor provides a flexible, mobile-optimized environment for modifying and inspecting Unreal Engine configuration files (Engine.ini, DeviceProfiles.ini, Scalability.ini, GameUserSettings.ini) directly on your device.

📸 Editing Modes Overview

To cater to different editing workflows, the Config Editor offers three dedicated modes: Smart Mode, Text (Raw) Mode, and One-Line Mode.

Smart Mode

Sectioned UI with value steppers, toggles, and negative number support.

Text (Raw) Mode

Direct multi-line editor with font-size controls and Search & Replace.

One-Line Mode

Quickly add or isolate a single CVar parameter in any target section.

✨ Detailed Mode Breakdown

1. 🧩 Smart Mode

Smart Mode parses your .ini files into collapsible, structured sections (e.g. [SystemSettings], [/Script/Engine.GarbageCollectionSettings]).

  • Inline Value Adjustments: Tap the pencil icon next to any key to edit its parameter.
  • Steppers & Negatives: Increment or decrement values easily with dedicated steppers (now with full negative number support).
  • Section Filtering: Collapse or expand sections to keep your editing workspace organized.

2. 📄 Text / Raw Mode

For power users who prefer working with direct raw code and configuration blocks.

  • Search & Replace: Quickly locate specific CVar strings across large config files.
  • Font Size Control: Adjust text size on-the-fly for comfortable viewing on any screen size.
  • Clean Syntax Preservation: Ensures formatting and indentation remain intact upon saving.

3. ⚡ One-Line Mode / Quick CVar

Allows adding or updating a single specific console variable without scrolling through hundreds of lines or risking accidental modifications to unrelated sections.

  • Targeted Injection: Select a target header (e.g. [SystemSettings]), specify the key (e.g. r.ShadowQuality), and input your desired value.
  • Isolation Editing: Safely preview changes before writing them to the active configuration.

🛡️ Engine CVar Section Guards

Auto-validates CVar placement across UE section headers and flags misplaced lines in vibrant red with a 1-tap Auto-Fix option.

🔄 Persistent Undo-Redo & Config Analyzer

  • Persistent History: Undo and redo actions persist across sessions, so you won't lose your change history even if you accidentally close the app.
  • Config Analyzer: Audits your active game configuration and highlights which CVar lines were successfully applied, overridden by the game engine, or deleted.

🎯 Popular Console Variables (CVars)

CVar / Variable Target Section Recommended Values Description
r.MobileContentScaleFactor [SystemSettings] 0.8 – 1.5 Scales 3D render resolution (lower for FPS, higher for clarity).
r.ShadowQuality [SystemSettings] 0 – 3 Sets shadow map resolution and dynamic cascading filters.
r.BloomQuality [SystemSettings] 0 (Off) – 2 Controls glare and bloom post-processing intensity.
r.VSync [SystemSettings] 0 (Off) / 1 (On) Disables vertical sync to reduce input lag on high-refresh displays.
