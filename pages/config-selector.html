Config Selector (v2.0.0 • Build 80)

Tab 3: UtilitiesScreen (Common Subtab)

Ten presets ship with the default repository and most of them will technically install on any phone. The Config Selector answers the question that actually matters: which one is worth running on your phone. It reads your chipset, GPU and memory, places the device in one of five tiers, then lists only the presets that tier can carry, best match first.

📍 WHERE TO FIND IT
Utilities → Common → Config Selector. It also opens by itself the first time you launch the app, right after the patching guide, and again each time you sync the default repository. A switch inside the dialog turns that second behaviour off.

The Five Tiers

Every device lands in exactly one tier, scored out of 100. The GPU carries the most weight because it is what these presets actually stress, followed by the chipset and then memory.

Flagship80 to 100Snapdragon 8 Gen series, Dimensity 9000 series, Immortalis GPUs
High end60 to 79Snapdragon 7 and 8s series, Dimensity 8000 series, Adreno 7xx
Mid end40 to 59Snapdragon 6 series, Dimensity 7000 series, Mali-G6xx
Low end20 to 39Snapdragon 4 series, Helio G series, older Adreno 6xx
Potato0 to 19Entry level chips that can still launch the game

Each preset has a floor: the weakest tier it is considered safe on. A flagship can run Potato Config perfectly well, it simply has no reason to, so the list is ordered by what suits your device rather than by what will merely install.

ℹ️ ABOUT Z_EXPERIMENTAL
Despite the name, this is a finished config and not a trial run. It ships alongside High-Visual Config as a refined take on it. The name is historical.

Matched Versus Estimated

The selector always tells you where its answer came from, because a recommendation you cannot judge the reliability of is worth very little.

  • Matched. Your phone or its chipset appears in a curated list of roughly 145 real devices. This is the author's own judgement about hardware that has actually been tested, and it always wins.
  • Estimated. Your hardware is not catalogued yet, so the score was calculated from the GPU, chipset and memory the app can read. The dialog labels this with an estimated tag. Treat it as a sensible starting point rather than a measurement.

Configs That Ship Several Versions

Some configs come in more than one flavour. Kodoupulse LowEnd Config, for example, ships a universal default, a Vulkan build, and one that adds the in-game Vulkan toggle. When that happens the selector lists each version as its own row so you choose, rather than picking one for you.

Applying a Recommendation

  1. Sync the repository from the Config tab first. The selector can only offer presets that are actually downloaded.
  2. Open Utilities → Config Selector.
  3. Read your tier and score at the top, and check whether it says matched or estimated.
  4. Tap a recommendation. If it ships several versions, tap the version you want.
  5. The app selects that preset and returns you to the Config tab. Tap 1-Click Patch to apply it.
⚠️ NOT IN THE SYNCED REPOSITORY
A preset marked this way exists in the catalogue but is not in the repository you have currently synced. Sync the default Arglax repository from the Config tab and reopen the selector. If you are using a custom repository, that preset may simply not be in it.

Looking Up a Different Device

The Look up another device section searches the same curated list by phone name, chipset or GPU. It is useful for checking what a friend's phone should run, or for seeing how your own device was classified.

Where the Device List Comes From

Creator & Technical Mechanics

The device list is fetched from the configuration repository when your phone is online and falls back to a copy bundled inside the app when it is not. A failed fetch is not an error worth interrupting you over: the bundled copy is complete, just potentially older, so the feature degrades to slightly out of date rather than broken. The dialog footer names whichever source was used.

Scoring weights the GPU renderer at 0.60, the chipset at 0.25 and memory at 0.15. The curated list is always consulted first and only an uncatalogued device falls through to that calculation, which is why the dialog distinguishes matched from estimated.

🔒 WHAT IT READS
The selector reads your GPU renderer string, chipset model and total memory. These are the same values shown by Get Device Info in Utilities. Nothing is uploaded and nothing leaves your phone.
