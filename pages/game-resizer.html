Game Resizer (v2.1.0 • Build 84)

Tab 1: ConfigScreen • Tab 3: UtilitiesScreen (Advanced Subtab)

The Game Resizer sets the resolution Wuthering Waves renders at. Lower it and the phone draws fewer pixels per frame, which is less work for the GPU: more frames, and a phone that stays cooler through a long session. Raise it, on a screen with the pixels to spare, and the game renders sharper than it otherwise would.

📍 WHERE TO FIND IT
Under the Launch Game button on the Config tab, and again under Utilities → Advanced → Game Resolution. Both are the same setting, so a change in one already shows in the other.
⚠ IT ONLY TOUCHES THE GAME
Your phone's own screen is never resized. Every other app, your launcher and the system interface keep looking exactly as they did. The patcher uses Android's own per-app game setting rather than changing your display.

Reading the Number

The scale is anchored at 1080p, so 1.00x means 1080p on every phone. 0.50x is 540p, 2.00x is 2160p, and the card shows the resolution next to the number. The same setting therefore means the same pixels whatever handset you are on, which is what makes a recommendation worth passing to someone else.

SliderGame renders atRoughly
0.50x540pA quarter of the pixels of 1080p. Lowest end devices.
0.75x810pNoticeably lighter, still readable text.
1.00x1080pThe usual mobile target.
1.50x1620pOnly on a QHD panel or better.
2.00x2160pOnly on a true 4K panel.

Why Your Slider Stops Where It Does

Android's per-app setting can only ask a game to render fewer pixels, never more than the screen itself has. So the top of the slider is simply your panel's own resolution, worked out from its short edge:

Your screenSlider tops out at
1080p (most phones)1.00x
1220p1.10x
1440p (QHD)1.30x
1644p1.50x
2160p (true 4K)2.00x

On a 1080p phone the slider is a downscale only, and that is not a limitation worth working around: the game was already drawing every pixel the screen can show.

Using It

  1. Open either card and drag the slider. The tile shows the scale, and the line under it shows the resolution.
  2. Let go. The setting is applied straight away and the status message confirms it.
  3. Restart the game. Android reads the setting when the game's process starts, so a game already running keeps its old resolution until you close and reopen it.
  4. Tap Reset at any time to turn it off and hand the game back its normal resolution.
💡 WHAT TO EXPECT
Measured on a 1220p phone: at 0.50x the game went from 2408x1080 to 1352x608, which is half the pixels per frame. The phone's own display stayed at 1220x2712 the whole time.

Requirements

RequirementWhy
Android 13 or newerThe per-app game setting this uses did not exist before Android 13. On an older phone the card says so and the slider stays put.
Shizuku, AXManager or rootChanging another app's settings needs elevated access, the same access the patcher already uses to write config files.

If Nothing Seems To Change

  • Restart the game properly. Close it from recents, not just back out of it.
  • A game can have its own ceiling. Wuthering Waves draws at 1080p at most on mobile, so on a screen taller than that the top of the slider will not look any different. That limit belongs to the game, not the patcher.
  • Check your access. If Shizuku stopped, the slider will tell you and offer to set it up again.
