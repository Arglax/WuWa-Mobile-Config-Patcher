Game Resizer (v2.1.1 • Build 86)

Tab 1: ConfigScreen • Tab 3: UtilitiesScreen (Advanced Subtab)

The Game Resizer sets the resolution Wuthering Waves renders at. Lower it and the phone draws fewer pixels per frame, which is less work for the GPU: more frames, and a phone that stays cooler through a long session.

📍 WHERE TO FIND IT
Under the Launch Game button on the Config tab, and again under Utilities → Advanced → Game Resolution. Both are the same setting, so a change in one already shows in the other.
⚠ IT ONLY TOUCHES THE GAME
Your phone's own screen is never resized. Every other app, your launcher and the system interface keep looking exactly as they did. The patcher uses Android's own per-app game setting rather than changing your display.

Reading the Slider

Each stop is a fraction of your own screen, and the card shows the resolution that works out to. On a 1080p phone 0.50x is 540p; on a 1220p phone the same 0.50x is 610p. A second figure next to it compares the result to 1080p, which is how most people talk about a mobile resolution.

Picking an Exact Resolution

Under the slider are one tap buttons for the usual resolutions: 360p, 480p, 540p, 720p, 900p and 1080p. Only the ones your screen can reach are shown, which is anything from 0.30x to 0.90x of your screen. Custom lets you type any height in that range, and tells you the range if you go outside it.

  • Android 14 and newer: you get exactly the height you pick. Measured on a 1220p phone, 480p rendered the game at 1064x480 and a custom 600p at 1328x600.
  • Android 13: Android only allows the slider's steps, so the patcher uses the closest one and says which. On a 1220p phone, 480p becomes 488p.

Why the Slider Has Thirteen Stops

The slider stops on 0.30x, 0.35x, and so on in steps of 0.05 up to 0.90x, plus Off. Those are the values every supported Android version accepts. Android 13 refuses anything else, which is also why exact resolutions are an Android 14 feature.

There is also no setting above 0.90x. The mechanism can only ask a game to draw fewer pixels than the screen has, never more, so Off is already the sharpest the game will get.

Using It

  1. Open either card and drag the slider, or tap a resolution button under it. The tile shows the resolution you are asking for.
  2. Let go. The setting is applied straight away and the status message confirms it.
  3. Restart the game. Android reads the setting when the game's process starts, so a game already running keeps its old resolution until you close and reopen it.
  4. Tap Reset at any time to turn it off and hand the game back its normal resolution.
💡 WHAT TO EXPECT
Measured on a 1220p phone: at 0.50x the game went from 2408x1080 to 1352x608, which is half the pixels per frame. The phone's own display stayed at 1220x2712 the whole time.

Requirements

RequirementWhy
Android 13 or newerThe per-app game setting this uses did not exist before Android 13. On an older phone the card says so and the slider stays put.
Shizuku, AXManager or rootChanging another app's settings needs elevated access, the same access the patcher already uses to write config files.
⚠ ANDROID 13 AND VERSION 2.1.0
In 2.1.0 the resizer failed on every Android 13 phone with a bare "exit code 255". Android 13 expects the request worded differently from newer versions, and that build only knew the newer wording. 2.1.1 fixes it. If you are on Android 13, update before trying again.

If Nothing Seems To Change

  • Restart the game properly. Close it from recents, not just back out of it.
  • A game can have its own ceiling. Wuthering Waves draws at 1080p at most on mobile, so on a screen taller than that the highest stops will look no different. That limit belongs to the game, not the patcher.
  • Check your access. If Shizuku stopped, the slider will tell you and offer to set it up again.
