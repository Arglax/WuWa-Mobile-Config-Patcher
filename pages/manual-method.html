Manual Mode Guide (Old School File Managers)

Fallback Workflow for Android 11 to 13

If you are unable to set up Shizuku, Wireless Debugging, or Root access, you can manually export presets from the patcher and paste them into the game's scoped storage folder using specialized file managers or USB PC transfers.

Manual Patching Instructions

  1. Install a Scoped Storage-compatible file manager such as FV File Explorer, ZArchiver, or MT Manager.
  2. In WuWa Config Patcher, go to Utilities > Export & Sharing > Share Patch to export your desired configuration archive.
  3. Extract the Engine.ini, DeviceProfiles.ini, and Scalability.ini files.
  4. Using your file explorer, copy the files and navigate to:
    /storage/emulated/0/Android/data/com.kurogame.wutheringwaves.global/files/UE4Game/Client/Client/Saved/Config/Android/
  5. Paste and overwrite the existing files.
  6. Launch Wuthering Waves.
ANDROID 14 / 15 PERMISSION RESTRICTIONS
On newer Android versions (Android 14 and 15+), Google has blocked third-party file managers without elevated Shizuku or Root access from reaching /Android/data/. In this scenario, setting up Shizuku or Root for WuWa Config Patcher is strictly required.
