1-Click Preset Patching Workflow

Tab 1: ConfigScreen

The Config Screen is designed for instantaneous 1-tap graphics optimization. It automatically downloads, parses, backs up, and injects verified community and official graphic presets directly into your game directory.

End-User Quick Steps

  1. Select Repository Source: By default, Arglax (Default) is active. Tap "Sync Files & Refresh" to fetch the latest presets.
  2. Choose a Preset: Browse through organized categories (STABLE, PERFORMANCE, HIGH_VISUAL, COMMUNITY, OTHER).
  3. Tap "1-Click Patch": The app creates a timestamped backup of your current setup and injects the new configuration.
  4. Tap "Launch Game": Triggers Wuthering Waves directly with your active tweaks.

Technical Mechanics & Repository Architecture

ConfigScanner, ZipExtractor & Shizuku IPC
Repository Sources

1. Repository Source Selector

  • Arglax (Default): Connects to GitHub API (GitHubApi.kt) to fetch preset metadata (custom-metadata.txt) and zip archives. Downloads share the app's network connection efficiently for snappier syncing.
  • Custom Online Repository: Direct HTTP/HTTPS .zip download URL input.
  • Local Repository: Calls SAF tree picker (OpenDocumentTree()) to select local directories containing offline INI presets.
  • Personal (Active Game Folder): Direct access to active on-device game configs with live vs app modification timestamp tracking.
Sync & Extraction

2. Sync Files & Deep Subfolder Scanning

  • Downloads archives and extracts ZIPs via ZipExtractor.kt into context.cacheDir/repo_cache/.
  • Parses preset folders using ConfigScanner.kt and ConfigNode.kt.
  • Deep Subfolder Fallback: Uses folder.walkTopDown() to discover nested .ini files in deep subfolders.
Preset Categorization

3. Categorization & 1-Click Injection

  • Categorizes presets into STABLE, PERFORMANCE, HIGH_VISUAL, COMMUNITY, and OTHER via PresetCategorization.kt.
  • Pre-mitigation & Backup: Automatically pre-creates missing .ini files with default templates before patching, and saves a timestamped backup in app_main_storage/backups/.
  • Injects files via elevated shell directly into .../Saved/Config/Android/ (supporting Engine.ini, DeviceProfiles.ini, Scalability.ini, and GameUserSettings.ini).

Preset Comparison Tool (v1.9.0)

PresetCompareDialog.kt & PresetDiffer.kt

In v1.9.0, users and preset creators can compare any preset against active running game configurations or other repository presets before applying patches.

🔍

Compare vs Active Game Configs

Compare any community or repository preset directly against your device's live running configuration (Personal (Active Game Folder)). Displays exactly what parameters will be modified, added, or removed in your game folder.

⚖️

Compare Preset vs Preset

Compare two different repository or local presets side-by-side (e.g., comparing Stable Low against Performance 60FPS) to inspect visual fidelity trade-offs and CVar adjustments.

SMART NUMERIC COMPARISON & SECTION MATCHING
The comparison engine (PresetDiffer.kt) intelligently handles canonical section alignment and floating-point equivalence (e.g. recognizing that 2.0 equals 2). Differences are highlighted in line-by-line diff views with instant filter controls.

Advanced Multi-Select Patching (v1.9.0)

AdvancedPatchDialog.kt & Gear Icon ⚙️

Tapping the Gear Icon (⚙️) next to the 1-Click Patch button opens AdvancedPatchDialog, granting multi-select control over individual configuration files within a preset package.

Granular File Selection Features

  • Selective File Targeting: Multi-select which specific files to apply:
    • Engine.ini (Core graphics & renderer overrides)
    • DeviceProfiles.ini (Vulkan, resolution scaling & device score)
    • Scalability.ini (Quality bucket presets)
    • GameUserSettings.ini (In-game graphics toggle states)
  • Master Toggle ("Apply ALL .ini files found"): Instantly checks or unchecks all available configuration files in the preset.
  • Automatic Availability Check: Disables checkboxes for configuration files not present in the selected preset package, preventing invalid file writes while allowing surgical updates (e.g. updating Engine.ini while preserving your custom DeviceProfiles.ini).

Reverting to Vanilla (Factory Game Defaults)

Restoring Original State

If you experience graphical stutters, visual artifacts, or game updates, you can restore clean factory game defaults in two ways:

🔴

Standard Revert (1-Tap)

Go to Utilities > Common > Vanilla mode and tap the primary red "Revert to Vanilla" button. This safely executes elevated deletion of Engine.ini, DeviceProfiles.ini, and Scalability.ini, prompting Wuthering Waves to regenerate pristine defaults upon next launch.

⚙️

Advanced Revert & Backup Restores

Tap "Advanced Revert" (opens AdvancedRevertDialog.kt) to selectively delete individual INIs, or go to Advanced Tools > Main Storage to restore a previous timestamped backup snapshot from context.filesDir/app_main_storage/backups/.
