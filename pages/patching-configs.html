Getting & Applying Config Presets[cite: 5]

WuWa Config Patcher provides three seamless repository sources to fetch and inject graphics presets:[cite: 5]

Method 1: Default Repository (Arglax & Community Presets)[cite: 5]

  1. Open the Config tab.[cite: 5]
  2. Set Repository Source to Arglax (Default). This securely connects to the GitHub API (GitHubApi.kt) to fetch custom-metadata.txt and official zip archives[cite: 1].
  3. Tap Sync Files & Refresh. The app extracts archives via ZipExtractor.kt into context.cacheDir/repo_cache/ and recursively parses preset directories using ConfigScanner.kt[cite: 1].
  4. Select your target device preset (categorized automatically into STABLE, PERFORMANCE, HIGH_VISUAL, etc. via PresetCategorization.kt)[cite: 1].
  5. Tap 1-Click Patch. A timestamped backup is generated in app_main_storage/backups/ via MainStorageManager.kt before files are routed directly to the game using elevated Shizuku IPC (ShizukuManager.applyAllIniFiles)[cite: 1].

Method 2: Custom Online Repository (.zip Download Link)[cite: 5]

  1. Go to Config tab $\rightarrow$ select Custom Online Repository.[cite: 5]
  2. Paste the direct HTTP/HTTPS URL to your custom .zip config pack[cite: 1].
  3. Tap Sync Files & Refresh and apply via 1-Click Patch.[cite: 5]

Method 3: Local Repository (On-Device Folder)[cite: 5]

  1. Go to Config tab $\rightarrow$ select Local Repository.[cite: 5]
  2. Tap Select Folder to invoke the SAF Tree Picker (OpenDocumentTree) and pick the directory containing your custom config files[cite: 1].
  3. Tap Use this Folder, sync, and apply via 1-Click Patch.[cite: 5]
PER-FILE ADVANCED PATCHING

To apply only a specific file (e.g. Engine.ini without touching DeviceProfiles.ini), tap the Gear Icon (⚙️) beside 1-Click Patch to open AdvancedPatchDialog.kt and selectively route individual files[cite: 1].

GAME LAUNCHER RESOLUTION

The "Launch Game" button intelligently resolves package availability across com.kurogame.wutheringwaves.global, .bilibili, .kuro, .tw, .jp, and .kr before triggering the launch intent[cite: 1].
