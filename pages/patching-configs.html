1-Click Preset Patching Workflow

Tab 1: ConfigScreen

The Config screen is designed for instantaneous 1-tap optimization. It automatically downloads, parses, and injects verified community and official graphic presets into your game directory.

End-User Quick Steps

  1. Select Repository Source: By default, Arglax (Default) is selected. Tap "Sync Files & Refresh" to fetch the latest presets.
  2. Choose a Preset: Browse through categories (STABLE, PERFORMANCE, HIGH_VISUAL, COMMUNITY).
  3. Tap "1-Click Patch": The app automatically creates a timestamped backup of your current setup and injects the new configuration.
  4. Tap "Launch Game": Starts Wuthering Waves with your active tweaks.

Advanced Patching & Repository Options

For Tweakers & Preset Creators
Gear Icon ⚙️

Per-File Granular Patching

Tapping the gear icon next to 1-Click Patch opens AdvancedPatchDialog.kt. This allows creators to selectively toggle which files to inject:

  • Engine.ini — Core rendering variables & system settings.
  • DeviceProfiles.ini — Device profile CVars & memory scaling.
  • Scalability.ini — Low/Medium/High/Cinematic preset overrides.
Custom Repositories

Custom Online & Local SAF Repos

Under the Repository Status Card, select:

  • Custom Online Repository: Enter a custom HTTP/HTTPS .zip URL containing community presets.
  • Local Repository: Select a local device folder via SAF to load offline INI presets.
  • Deep Subfolder Fallback: ConfigNode.kt uses folder.walkTopDown() to discover nested presets in deep subfolders.

Reverting to Vanilla (Factory Game Defaults)

Restoring Original State

If you experience graphical glitches, unexpected stuttering, or game updates, you can restore clean vanilla game defaults in two ways:

🔴

Standard Revert (1-Tap)

Go to Utilities > Common > Vanilla mode and tap the red "Revert to Vanilla" button. This safely removes Engine.ini, DeviceProfiles.ini, and Scalability.ini, prompting the game to regenerate pristine defaults upon next launch.

⚙️

Advanced Revert & Restore

Tap "Advanced Revert" to selectively delete specific INIs, or go to Utilities > Advanced > Main Storage to restore a previous timestamped backup snapshot from context.filesDir/app_main_storage/backups/.
