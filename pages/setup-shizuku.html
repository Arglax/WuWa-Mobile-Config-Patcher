Prerequisites & Elevated Access Backends

Target SDK 36 • Android 11 to 15+

On Android 11+, Google restricts access to /Android/data/ via Scoped Storage. WuWa Config Patcher bypasses these limitations using elevated IPC backends so you can patch files without needing a PC or a rooted device.

⚡

Shizuku (Recommended)

Runs via Android Wireless Debugging or ADB. Requires zero root and grants direct access across app reboots.

👑

Root Access (Magisk/KernelSU/APatch)

Direct elevated root shell execution (su -c id). Fully automated 1-tap grant.

🔷

AxManager Provider

Third-party Axeron shell provider integration for devices with dedicated optimizer suites.

Standard Guide: Setting up Shizuku (Wireless Debugging)

End-User Setup (No Root Required)

Step-by-Step Wireless Debugging Pairing

  1. Download and install Shizuku from Google Play or GitHub.
  2. Connect your device to Wi-Fi (or turn on a Portable Wi-Fi Hotspot on your phone).
  3. Go to Settings > Developer Options on your phone.
    • Enable Developer Options (tap Build Number 7 times in About Phone).
    • Enable USB Debugging and Wireless Debugging.
  4. Open Shizuku, tap Pairing > Developer Options, then tap Pair device with pairing code.
  5. Enter the 6-digit code in the Shizuku notification prompt.
  6. Return to Shizuku and tap Start.
  7. Open WuWa Config Patcher and grant Shizuku permission when prompted.
XIAOMI / HYPEROS / MIUI USERS
You must enable "USB Debugging (Security Settings)" inside Developer Options. This requires a signed-in Mi Account and allows Shizuku to grant file system write permissions.

Technical Deep-Dive: Elevation Architecture

For Developers & Advanced Tweakers
Backend Verification Logic (ShizukuManager.kt)
// 1. Shizuku Binder IPC Check
val isShizukuAvailable = Shizuku.pingBinder()
if (isShizukuAvailable && Shizuku.checkSelfPermission() == PackageManager.PERMISSION_GRANTED) {
    activeBackend = AccessBackend.SHIZUKU // Green Badge
}

// 2. Direct Root Shell Fallback
else if (Shell.cmd("id").exec().isSuccess) {
    activeBackend = AccessBackend.ROOT // Red Badge
}

// 3. Axeron Provider Detection
else if (AxManager.isAvailable()) {
    activeBackend = AccessBackend.AXMANAGER // Blue Badge
}

When 1-Click Patch is triggered, the patcher uses Shizuku's IFileSystem service to write directly to /storage/emulated/0/Android/data/com.kurogame.wutheringwaves.global/files/UE4Game/Client/Client/Saved/Config/Android/ without touching standard Android SAF document trees.
