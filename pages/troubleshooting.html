Troubleshooting & Frequently Asked Questions

v1.5.0 Support Reference

1. Shizuku is Running, but App Shows "NONE" or Requests Access

If your Elevated Access Status shows "NONE" despite Shizuku running in the background:

  1. Go to the Settings tab and check the Elevated Access Status card.
  2. Tap the refresh button next to the Shizuku setup wizard.
  3. If it fails, open the Shizuku app, revoke permissions for WuWa Config Patcher, and force stop the patcher. Reopen the patcher to trigger the prompt again via rikka.shizuku.api.

2. Game Stuttering or Crashing After Patching

Not all mobile devices handle extreme visual presets well. To safely reset your game graphics to Kuro Games' defaults:

  1. Navigate to the Utilities tab $\rightarrow$ Common Subtab.
  2. Tap the primary red Revert to Vanilla button.
  3. Confirm the prompt. This automatically executes a safe deletion of Engine.ini, DeviceProfiles.ini, and Scalability.ini.

3. What do the Access Badges Mean?

  • ROOT — Red badge (#E35D6A): Direct elevated libsu shell execution.
  • SHIZUKU — Green badge (#47D764): Primary wireless debugging ADB backend.
  • AXMANAGER — Blue badge (#2AA37D): Axeron community provider helper.
  • SHIZUKU_UNAUTHORIZED — Orange badge (#F7C948): Shizuku binder running, permission pending.
  • NONE — Gray badge (#A8B4AF): No elevated backend available.

4. Editor Saves are Flagged in Vibrant Red (#FF2222)

The Config Editor enforces strict CVar Section Guards via CVarSectionGuard.kt. Misplaced lines or Engine.ini CVars= prefixes are painted bold Vibrant Red.

  1. When you tap Save, select Auto-Fix Sections in the warning prompt.
  2. The app will automatically route your CVars to canonical section headers (e.g. s. commands to [/Script/Engine.StreamingSettings]) and strip invalid CVars= prefixes.
  3. Note: [Core.Paths], [Core.System], and [/Script/Engine.RendererOverrideSettings] are whitelisted and never altered.

5. Internal Device Storage Full from Game Logs

Wuthering Waves can generate massive log files over time. To clean them:

  1. Go to Utilities $\rightarrow$ Common Subtab $\rightarrow$ Log Tools.
  2. Tap Delete Logs to execute an elevated rm -rf on the .../Saved/Logs/ directory safely.

6. Shader Compilation Crashes or Graphical Artifacts

If you experience rendering artifacts or crashes during shader compilation after game updates:

  1. Go to Settings Tab > Danger Zone.
  2. Tap Delete Shaders. This opens DeleteShadersDialog.kt.
  3. Select and delete Vulkan (VulkanProgramBinaryCache) or OpenGL (ProgramBinaryCache) shader caches to force a clean shader rebuild upon next launch.
