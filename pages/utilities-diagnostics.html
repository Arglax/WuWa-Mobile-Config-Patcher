Common Utilities & Hardware Diagnostics (v1.9.0 • Build 73)

Tab 3: UtilitiesScreen (Common Subtab)

The Common Subtab on the Utilities tab provides essential tools for automated app self-diagnosis, log decryption, custom theme customization, device hardware scanning, telemetry privacy controls, config exporting, and vanilla game reverts in v1.9.0 (versionCode 73).

🩺 App Doctor Self-Diagnosis & Auto-Repair

Automated diagnostic engine (AppDoctor.kt) that audits 7 core health indicators: Elevated Access status (Shizuku/Root), Wuthering Waves application package installation, game config directory reachability, config repository validity (auto re-syncs if missing or corrupt), cache & download folder health (auto-cleans broken or orphaned zips), app storage report integrity (purges zero-byte files), and recent error log pattern scans. Automatically repairs safe issues with 1 tap or routes unresolved errors to the Bug Report flow.

🎨 Custom Theme Builder & Color Swatches

Integrated theme engine (ThemeSystem.kt) offering predefined theme swatches (Midnight Obsidian, Kuro Amber, Cyberpunk Neon, Emerald Mint, Slate Dark, Pure OLED, Light Mode) alongside an interactive Custom Theme Builder. Customize primary, secondary, and accent colors with color picker swatches, live preview, and persistent user theme storage.

🔓 Log Decryptor Engine

Decrypts obfuscated game logs via LogDecryptor.kt (supporting Scheme A XOR 0xA5/0xEF, Scheme B XOR 0x55, or plaintext fallback). Supports full-screen DecryptedLogViewerDialog.kt and Sharesheet export with quick inline filter chips (LogConfig, GameThread, Sharphereal, LogInit, LogTemp, Vulkan, RHI) and automatic prompt if no log is present.

📊 Telemetry & Analytics Dashboard Controls

Full control over anonymous app usage metrics (TelemetryManager.kt / FeatureContract). Opt-in or opt-out anytime via Settings or Utilities. Collects high-level feature interaction metrics, diagnostic error telemetry, hardware profile telemetry, and crash telemetry with zero PII (Personally Identifiable Information) collection.

📱 Get Device Info

Invokes DeviceStatsCollector.kt to extract your exact GPU renderer model, Vulkan driver version, physical RAM, CPU core count, C# environment status, and game-evaluated Device Score from log headers.

📦 Export & Sharing

Opens SAF tree folder (PatchExporter.kt) or compresses active live INI configs into a ZIP archive with custom naming dialog before opening the Android Sharesheet.

🗑️ Delete Logs

Executes an elevated rm -rf command on the .../Saved/Logs/ directory safely to clear GBs of bloated log files from internal storage.

🔴 Revert to Vanilla (3-Step Triple Guard)

Safely deletes modified INI files (Engine.ini, DeviceProfiles.ini, Scalability.ini) using a 3-step triple guard confirmation sequence to force Wuthering Waves to regenerate clean Kuro Games defaults upon launch.

🖥️ Config Monitor (KuroConfigMonitor.hash)

View Config Monitor: Displays KuroConfigMonitor.hash in a tabulated card view showing modification frequencies, timestamp, and hash per INI file.
Reset Config Monitor: Deletes the Config directory (.../UE4Game/Client/Client/Config) to reset engine monitoring state (logged in Activity Log).
