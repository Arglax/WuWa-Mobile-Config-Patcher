Utilities Suite & Diagnostics Guide[cite: 7]

Access the Utilities tab for deep hardware scans, log tools, and persistent backups. The screen is divided into Common and Advanced subtabs:[cite: 1]

Get Device Info

Invokes DeviceStatsCollector.kt to extract hidden hardware specs (GPU model, physical RAM, CPU cores, C# environment status, and Device Score) directly from game logs[cite: 1].

Log Decryptor & Explorer

Uses LogDecryptor.kt (supporting Scheme A XOR 0xA5/0xEF, Scheme B XOR 0x55, and Plaintext fallback) to read obfuscated Client.log files. Features inline search, filter chips (LogConfig, GameThread, Sharphereal, Vulkan, RHI), and a full-screen DecryptedLogViewerDialog.kt[cite: 1].

Analyze Config

Invokes CVarAnalyzer.kt to cross-check live INI CVars against the latest instance in Client.log. Generates ConfigAnalysisDialog.kt featuring a 5-column filterable status table displaying Applied, Failed, and Deleted metrics[cite: 1].

Extract Log CVars

Invokes CVarExtractor.kt to parse the decrypted log line-by-line, assigning change frequency remarks (Static, Var 1, Var 2, Var 3, Hyper) and allowing TXT/CSV exports[cite: 1].

Duplicate Flagger

Uses DuplicateCvarFlagger.kt to scan active INIs for duplicate entries across sections, allowing 1-tap interactive resolution via DuplicateFlaggerDialog.kt while protecting metadata pointers[cite: 1].

Strip Forbidden CVars

Detects and strips forbidden CVars that are ignored at runtime using ForbiddenCvarStripper.kt. Displays ForbiddenCvarDialog.kt with a 1-tap Auto Strip All action[cite: 1].

CVar Bank & Reference

Searchable library of 1000+ CVars loaded asynchronously via loadAlteriaXAssetsIfNeeded(). Includes Card/Table views, dynamic web text extraction, and a 1-tap "Send to Editor" function[cite: 1].

Main Storage Reader

Opens MainStorageReaderDialog.kt to view, copy, share, or 1-tap Restore Backup from the persistent context.filesDir/app_main_storage/ directory[cite: 1].

Vanilla Revert & Diagnostics

Reverts graphics by executing elevated file deletion on Engine.ini, DeviceProfiles.ini, and Scalability.ini (or selectively via AdvancedRevertDialog.kt). You can also view backend processes via ActivityLogDialog.kt[cite: 1].
