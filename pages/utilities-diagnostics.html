Common Utilities & Hardware Diagnostics

Tab 3: UtilitiesScreen (Common Subtab)

The Common Subtab on the Utilities tab provides essential tools for log decryption, live log filtering, device hardware scans, config exporting, and vanilla game reverts.

🔍 Decrypted Log Explorer

Inline live line explorer for decrypted Client.log files with line numbers, search query input, and quick filter chips (LogConfig, GameThread, Sharphereal, LogInit, LogTemp, Vulkan, RHI).

📱 Get Device Info

Invokes DeviceStatsCollector.kt to extract your exact GPU renderer model, Vulkan driver version, physical RAM, CPU core count, C# environment status, and game-evaluated Device Score from log headers.

📦 Export & Sharing

Opens SAF tree folder (PatchExporter.kt) or compresses active live INI configs into a ZIP archive with custom naming dialog before opening the Android Sharesheet.

🔓 Log Decryptor Engine

Decrypts obfuscated game logs via LogDecryptor.kt (supporting Scheme A XOR 0xA5/0xEF, Scheme B XOR 0x55, or plaintext fallback). Supports full-screen DecryptedLogViewerDialog.kt and Sharesheet export.

🗑️ Delete Logs

Executes an elevated rm -rf command on the .../Saved/Logs/ directory safely to clear GBs of bloated log files from internal storage.

🔴 Revert to Vanilla

Safely deletes modified INI files (Engine.ini, DeviceProfiles.ini, Scalability.ini) to force Wuthering Waves to regenerate clean Kuro Games defaults upon launch.
